## 示例 A — 默认排雷（FULL_SCAN + light + normal）

✅ 世界观与伏笔设计广受好评（较可信）

❓ 结局口碑两极（评价两极）

## 核心排雷

后宫：无后宫（已确认）
NTR：未提及（未发现相关讨论，较可信）

水文：中后期篇幅膨胀明显（多来源一致，已确认）
剧情逻辑：整体严密，个别支线收束仓促（较可信）
世界观：宏大，核心卖点（已确认）
力量体系：自洽（较可信）
连载状态：已完结（已确认）
结局评价：两极（评价两极，见下）

## 示例 D — 详细 + 个人适配（FULL_SCAN + light + detailed，读取偏好）

# 《雾中灯塔》适不适合我？

剧透等级：轻微剧透
信息截至：2026-08-12

建议：不推荐

一句话匹配描述：世界观与力量体系正是你的加分项，但"重度水文"已确认命中你的硬雷——按硬雷规则，不因其他优点给高分，建议不推荐；若你能接受跳读，可在观望后再自行判断。

## 与你偏好的冲突（最重要的最前）

1. [硬雷·重度水文] 中后期明显篇幅膨胀（多来源一致，已确认）：硬雷命中 → 不推荐。

## 与你偏好的匹配

- like·宏大世界观：已确认，核心卖点 ✅
- like·力量体系自洽：较可信 ✅
- neutral·慢热：对你无影响

## 有争议 / 无法确认

- 结局两极（见上）；强行统计双方人数无意义，不作为建议依据。

## 最需要注意

- 若你仍想尝试：篇幅膨胀集中在 40~60 卷，前 10 卷体验不受影响，可读前 10 卷试水；但按你的硬雷配置，结论保持不推荐。

## 示例 F — 结局评价两极（FULL_SCAN + detailed + light）

> 请求："详细排雷《烬土回响》" → base_mode = FULL_SCAN; spoiler_level = light; detail_level = detailed
> **测试点（T314）**：dimension = ending-reception；value = mixed；confidence = CONFIRMED；agreement = DIVIDED。
> 目的：验证"有充分证据确认读者对结局评价明显两极"能被正确表达，且**不会**写成"结局信息不可靠"、"证据互相矛盾所以无法判断"、或"这本书烂尾"。
> 另演示 §4.4 可见性规则：本报告只展示 9 个重要维度 + 1 行"其余维度快速检查"，不是固定 16 行。

```md
# 《烬土回响》排雷

一句话结论：废土史诗群像文，设定自洽、群像扎实；结局是全书最大讨论点——注意区分：下面关于结局的结论是"读者评价分化"，不是"结局好坏"。

剧透等级：轻微剧透
信息截至：2026-08-12

## 先看结论

✅ 设定与群像塑造广受好评（已确认）
⚠ 中期 25~40 章节奏放缓（较可信）
❓ 结局口碑：明显两极——读者对结局的评价存在稳定分化（多来源一致）

## 核心排雷

感情线：单女主明确（已确认）
后宫：无（已确认）
NTR：无（已确认）
主角智商：在线，无降智抱怨（较可信）
慢热：中（较可信）
水文：无显著（较可信）
世界观：宏大，核心卖点（已确认）
力量体系：自洽（已确认）
连载状态：已完结（已确认）
结局评价：明显两极（多来源一致，已确认）

关于"结局评价"的准确含义，请务必理解三点：

1. 可以确认的是：读者对结局的评价存在稳定分化。多篇独立长评与讨论帖指向同一裂痕，且结论跨日期一致，不是一次性情绪。
2. 分化内容：一部分读者主要批评——结局收束过快、个别配角线未交代；另一部分读者则认为——结局主题完成度高、落点诚实。
3. 这意味着：本报告高可信地确认"评价分化"这个事实，而不是确认"结局客观好或坏"。具体取舍请按上述两派观点自行判断。
   （注意：这不是"信息不可靠"，也不是"互相矛盾所以无法判断"——分歧本身是结论。本轮不描述结局具体内容，剧透等级保持：轻微剧透。）

其余维度快速检查：无系统、无圣母倾向、无严重虐主、行事果断中等、套路重复低、剧情逻辑整体严密——均无显著雷点（依据见下）。

## 最需要注意

1. 若你属于"结局决定整本书评价"的读者：本作结局分歧明显，建议先读完上面两派观点再决定是否开坑。
2. 中期节奏放缓是社区一致观察（较可信），不是个人感受差异；节奏敏感型读者请把这个风险纳入考虑。

## 和你的偏好

未配置个人偏好，本次只进行客观排雷，不进行个人适配评分。

## 有争议 / 无法确认

- 个别配角线是否真"未交代"：属于各人观感差异，不影响"评价分化"这一结论本身。
- 慢热程度：社区表述介于"中"与"中高"之间，不足以定性为重度慢热。

## 依据

- 官方作品页（已完结 · 共 96 章，2026-06-30）
- 完结后长评《烬土回响：一场收束的争议》（2026-07-08）
- 书评社区讨论帖"结局到底算不算好"系列（2026-07）
- 读者长评《它把伏笔都收了，所以呢》（2026-07-21）
```
